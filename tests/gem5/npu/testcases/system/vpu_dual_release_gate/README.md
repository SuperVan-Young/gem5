# VPU 双设备释放门控测试

## 测试目的

验证双 VPU 系统在 release gate 控制下的并发调度行为是否稳定，包括命令阻塞、释放后继续执行以及最终统计计数。

## 仿真系统

该 testcase 使用单 CPU timing 系统、默认物理内存、一个 `MegaCmdQueue` 和一个包含两个 VPU 实例的共享 `SEU` 子系统。
测试重点是同步释放门控和双 VPU 并发行为，不单独强调某一个算子本身。

## 仿真程序

workload 先为两个 VPU 准备各自的数据和目标输出，然后在释放信号发出之前确认输出保持不变。
释放信号到达后，程序等待两个 VPU 分别完成一次执行，并验证结果和关键统计。

## 预期行为

仿真结束时，命令队列和两个 VPU 的占用应归零，两个 VPU 都应处于空闲状态，统计计数与预期一致，并输出稳定的通过标记 `SYSTEM_VPU_DUAL_RELEASE_GATE_PASS`。
